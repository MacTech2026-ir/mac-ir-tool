Connect Gmail
Authorizes read-only access to your Vendors/Ingersoll Rand label. Nothing is modified or sent. All techs use the synced data — only you need to connect Gmail.
⚙ Requires GMAIL_CLIENT_ID and GMAIL_CLIENT_SECRET set in your Railway environment variables. See the setup guide below.
Setup (one time):
1. Go to console.cloud.google.com
2. Create project → Enable Gmail API
3. Credentials → OAuth 2.0 Client ID → Web Application
4. Add your Railway URL as authorized redirect URI:
https://your-app.railway.app/auth/callback
5. Copy Client ID + Secret → paste into Railway environment variables
